# Changelog

## [0.1.0] - 2026-10-05

### Added
- Driver-based Stable implementations for GRE, HAProxy, rinetd, socat, GOST and wstunnel.
- Experimental catalog for WireGuard, FRP, Chisel, Rathole and Backhaul TCPMUX.
- Separate Iran service endpoint and Foreign destination endpoint.
- JSON state, JSONL history, rollback and ownership-safe cleanup.
- H0-H5 health model with authenticated H3 byte-path validation.
- Manual two-command and SSH-orchestrated deployment modes.
- Safe benchmark profiles and release/CI workflows.
